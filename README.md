# Coffee Sales Analysis with Excel

## 1. Project Overview

This project focuses on cleaning, organizing, and analyzing coffee sales data using Microsoft Excel. The goal is to explore sales performance across different years, countries, and product categories through data analysis and visualization.

## 2. Tools & Skills

- **Microsoft Excel:** Data cleaning and formatting
- **Excel Functions:** XLOOKUP, INDEX, MATCH
- **Data Analysis:** PivotTables and PivotCharts
- **Data Visualization:** Charts and dashboard

## 3. Data Preparation

- Cleaned and standardized the dataset.
- Adjusted column formats and organized data for analysis.
- Used XLOOKUP, INDEX, and MATCH to retrieve and combine information across multiple worksheets.

## 4. Analysis

The project explores sales performance from different perspectives:

- Sales trends over time.
- Sales performance by country.
- Sales by product category and subcategory.
- Top 5 customers by sales.

## 5. Dashboard

An Excel dashboard was created to present key sales insights through charts and summary metrics.

**File:** `coffeeOrdersData.xlsx`
